# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-11-11

Первый публичный релиз.

### Добавлено

- **Пилюля** у верхнего края экрана: часы, живые активности (трек, таймер, погода, CPU и память), счётчик непрочитанных уведомлений, индикатор состояния.
- **Мини-персонаж** — пара SVG-глаз: неровное моргание (иногда двойное), слежение зрачками за курсором, оглядывание без движения мыши и пять выражений — довольное, сосредоточенное, сонное, встревоженное, спокойное.
- **Капли**, стекающие снаружи островка: canvas поверх корпуса с отсечением по силуэту, «бусины» по всей нижней кромке, набухание, срыв и падение; тонируются акцентом темы.
- **Панель** из пяти разделов: обзор, система, фокус, ассистент, настройки.
- **Плеер** в стиле Apple «Now Playing»: обложка, эквалайзер, скраббер с перетаскиванием и управлением с клавиатуры, честная перемотка через SMTC.
- **Погода**: поиск по любому городу мира, до 8 сохранённых мест, `°C`/`°F`, прогноз на 4 дня, кэш с офлайн-фолбэком.
- **Системный монитор**: CPU, память, диски, сеть, батарея, топ процессов, аптайм, сведения о машине, найденный VPN.
- **Таймер фокуса** с кольцом прогресса, дублированием в пилюле и уведомлением по завершении.
- **Ассистент**: локальные команды без интернета и свободные вопросы через OpenAI-совместимый API.
- **10 акцентов темы**, эффекты и сквозные клики — в настройках; журнал диагностики там же.

### Техническое

- Tauri 2 + Rust: Win32-окно (прозрачность, без рамки, click-through, привязка к верхнему краю), `sysinfo`, SMTC через WinRT (`windows` crate).
- Интерфейс на TypeScript и Vite без UI-фреймворков; собственный набор SVG-иконок и canvas-эффекты.
- Иконка генерируется кодом (`scripts/make-icon.mjs`, PNG + многоразмерный `.ico`, без зависимостей).
- Портативная сборка `.exe` без установщика: `npm run exe`.
- CI на GitHub Actions: проверка `tsc` + `vite build`, сборка портативного `.exe` и приложение к релизу по тегу `v*`.
