# Как помочь проекту

Спасибо, что заглянули. Island — небольшое приложение, поэтому здесь ценятся маленькие точные изменения, а не большие переписывания.

## Окружение

```powershell
npm install          # зависимости интерфейса
npm run tauri dev    # приложение целиком (Vite + Rust)
npm run build        # только гейт качества: tsc + vite build
```

Нужны Windows 10/11, Node.js 20+, Rust stable (MSVC) и C++ Build Tools.

## Правила

Полный список — в [`system-design.md`](system-design.md). Коротко:

- слои идут только внутрь: `ui → services → core/bridge → Rust`; `ui/` не вызывает `invoke` напрямую;
- никакого `console.log` — только `core/logger.ts`;
- ошибки не глотаются: сеть и нативные вызовы обёрнуты и попадают в журнал;
- внешний текст (треки, процессы, города, ответы модели) вставляется в `innerHTML` только через `escapeHtml`;
- системные действия — только по белому списку в `window_api.rs`;
- новый код не тянет зависимостей, если задачу решают 30 строк на месте;
- интерфейсные строки — на русском, имена и doc-комментарии — по стилю проекта;
- интерактив — настоящие `button` с `aria-*`, уважается `prefers-reduced-motion`.

## Коммиты

[Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `style:`, `refactor:`, `docs:`, `build:`, `chore:`.

```
feat(player): перемотка через SMTC
fix(pill): глаза больше не подменяются дугами
```

## Pull request

1. Форк → ветка от `main` (`feat/short-name`).
2. Изменение + проверка `npm run build` (и `npm run tauri dev`, если затронут Rust).
3. PR по шаблону: что меняется, как проверить, скриншоты при изменении внешнего вида.

## Что не подойдёт

- новые UI-фреймворки и CSS-препроцессоры: интерфейс сознательно собран на нативном DOM и CSS-переменных;
- фоновые службы, драйверы и отдельные установщики — Island остаётся одним `.exe`;
- «демонстрационные» данные вместо честного «данные недоступны»;
- изменения, ломающие `prefers-reduced-motion` и клавиатурное управление.
