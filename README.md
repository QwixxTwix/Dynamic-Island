# Island

**Dynamic Island для Windows.** Прозрачная пилюля у верхнего края экрана: живые активности, мини-персонаж, стекающие капли — и раскрывающаяся панель с медиаплеером, системным монитором, погодой, таймером фокуса и ассистентом.

## Установка

1. Откройте [**Releases**](../../releases) и скачайте `island.exe` из последнего релиза.
2. Положите файл в любую папку и запустите — установщик не нужен, ярлыки и записи в реестр не создаются.
3. Пилюля появится по центру верхнего края основного монитора, поверх всех окон.

Единственное требование — **WebView2 Runtime**: в Windows 11 он уже входит в систему, в Windows 10 обычно ставится вместе с Microsoft Edge. Если рантайма нет, приложение честно сообщит об этом вместо пустого окна.

> Первый запуск может занять пару секунд: система проверяет подпись файла. Windows SmartScreen может показать предупреждение — сборка не подписана сертификатом разработчика, это нормально для открытых утилит.

Выйти из приложения — **Настройки → Выйти из Island** (свернуть панель — `Esc` или клик по пилюле).

## Возможности

### Свёрнутая пилюля · 248 × 40

- **Мини-персонаж — только пара глаз.** Моргает с неровным интервалом (иногда дважды подряд), следит зрачками за курсором, а когда мышь замирает — лениво оглядывается. Настроение выводится из состояния машины:

  | Настроение | Когда | Как выглядит |
  | --- | --- | --- |
  | довольное | играет музыка | глаза распахнуты, персонаж подпрыгивает |
  | сосредоточенное | идёт таймер фокуса | прищур, медленное сканирование |
  | сонное | ночь (23:00–06:00) и тишина | веки полуопущены, «клюёт носом» |
  | встревоженное | CPU ≥ 85 %, батарея < 20 % без зарядки, нет нативных данных | глаза скошены внутрь, микро-дрожь |
  | спокойное | по умолчанию | ровные глаза с бликом |

  Выражение строится только на форме века и положении зрачка — глаза никогда не подменяются дугами `^ ^`, поэтому персонаж не выглядит «вечно спящим».
- **Капли, стекающие с островка.** Canvas лежит поверх корпуса, но рисунок отсечён по силуэту (`clip("evenodd")`), поэтому вода видна **только снаружи**: бусины распределены по всей нижней кромке вместе со скруглениями, набухают, срываются, вытягиваются по скорости и гаснут. Тонируются акцентом темы.
- **Живые активности**, сменяющие друг друга каждые ~5 секунд: текущий трек, обратный отсчёт таймера, погода, загрузка CPU и памяти.
- **Часы и дата**, счётчик непрочитанных уведомлений и индикатор состояния: акцентный — всё в порядке, жёлтый — включены сквозные клики, серый — нативные данные недоступны.

### Панель · 500 × 560, пять разделов

| Раздел | Что внутри |
| --- | --- |
| **Обзор** | часы, погодная карточка с прогнозом на 4 дня (ощущаемая температура, ветер, влажность), плеер в стиле Apple «Now Playing», быстрые действия Windows, лента уведомлений |
| **Система** | CPU, память, диск, батарея, скорость сети, топ процессов, аптайм, сведения о машине и найденный VPN-интерфейс |
| **Фокус** | таймер на 5/15/25/45/60 минут или своё значение, кольцо прогресса, дублирование отсчёта в пилюле и уведомление по завершении |
| **Ассистент** | локальные команды без интернета («таймер 25», «пауза», «погода») и свободные вопросы через любой OpenAI-совместимый API с вашим ключом |
| **Настройки** | поверх окон, секунды в часах, сквозные клики на 60 секунд, эффекты (капли и живой персонаж), поиск по любому городу мира, `°C`/`°F`, 10 акцентов темы, интервал опроса, ключ ассистента, журнал диагностики |

### Плеер

Настоящий «Now Playing», а не картинка: обложка из системного кэша, скраббер с перетаскиванием и управлением с клавиатуры (`←`/`→` по 5 секунд, `Home`/`End` — в начало и конец), play/pause, переключение треков. Перемотка работает через SMTC (`TryChangePlaybackPositionAsync`), поэтому управляет любым плеером, зарегистрированным в системе.

### Погода

Поиск по любому городу мира через геокодер Open-Meteo — «Токио», «Tokyo» и «Нью-Йорк» находят одно и то же место. Сохраняется до 8 городов, переключение одним кликом, единицы `°C`/`°F`, при обрыве сети показывается последний удачный снимок.

### Нативная интеграция (Rust)

- `sysinfo` — CPU, память, диски, сеть, процессы;
- SMTC через WinRT (`windows` crate) — Spotify, AIMP, браузеры, «Медиаплеер» и любой другой источник медиасессии;
- Win32-окно: прозрачность, без рамки, всегда сверху, сквозные клики, привязка к центру верхнего края монитора;
- запуск системных средств по закрытому белому списку — никакой произвольной команды из интерфейса.

## Управление

| Действие | Как |
| --- | --- |
| Раскрыть / свернуть панель | клик по пилюле |
| Свернуть | `Esc` |

| Выйти | Настройки → «Выйти из Island» |

## Стек

| Слой | Технологии |
| --- | --- |
| Интерфейс | TypeScript, Vite 6, нативный DOM без UI-фреймворков; собственный набор SVG-иконок и canvas-эффекты |
| Оболочка | Tauri 2 (Rust): окно, IPC-команды, прозрачность и click-through |
| Система | `sysinfo`, WinRT `Media_Control` / `Storage_Streams`, Win32 |
| Стиль | тёмная тема Apple HIG: системная нейтральная шкала, системные цвета, непрерывные радиусы, пружинная кривая `--ease-ios` |

Сборка — один `.exe` примерно на 6,6 МБ: интерфейс, иконка и манифест встроены в бинарник, рядом ничего не требуется.

## Сборка из исходников

### Требования

- Windows 10/11 с WebView2 Runtime;
- [Node.js](https://nodejs.org/) 20+ и npm;
- Rust stable с toolchain MSVC ([rustup](https://rustup.rs/));
- C++ Build Tools из Visual Studio (Desktop development with C++).

### Разработка

```powershell
git clone <url-репозитория>
cd island
npm install
npm run tauri dev
```

Vite поднимается на `127.0.0.1:1420`, Tauri собирает debug-бинарник и открывает окно. Горячая замена работает для интерфейса; правки в `src-tauri/**` пересобирают Rust.

### Портативный `.exe`

```powershell
npm run exe
```

Готовый файл — `src-tauri/target/release/island.exe`. Скрипт вызывает `tauri build --no-bundle`, поэтому не нужны WiX/NSIS и интернет после первого `cargo fetch`. Профиль release настроен на размер: `opt-level = "s"`, `lto = true`, `codegen-units = 1`, `strip = true` — первая сборка долгая, последующие быстрее.

### Установщик

```powershell
npm run tauri build
```

Tauri сам скачает инструменты и соберёт `.msi` и NSIS-`.exe` в `src-tauri/target/release/bundle/`.

### Только интерфейс

```powershell
npm run dev      # откройте http://127.0.0.1:1420 в браузере
npm run build    # tsc + vite build, без нативной части
```

В браузере нативных данных нет — разделы честно показывают «данные недоступны», а не выдуманные проценты.

### Иконка

Нарисована кодом: `scripts/make-icon.mjs` собирает PNG-набор (16–256) и многоразмерный `icon.ico` через `zlib` и CRC32 — без зависимостей и графических редакторов. Запускается автоматически перед `dev` и `build` (`predev` / `prebuild`), вручную — `npm run icons`. Векторный вариант для интерфейса — `public/icon.svg`.

## Архитектура

```
src/
  core/        bridge к Rust (единственная точка IPC), журнал, наблюдатели — без DOM
  services/    состояние и побочные эффекты: система, медиа, погода, фокус,
               ассистент, настройки, уведомления
  lib/         чистые функции форматирования и экранирования
  ui/          разметка и обработчики: пилюля, панель, разделы,
               набор SVG-иконок (icons.ts), виджеты (widgets.ts),
               персонаж (mascot.ts) и капли (drips.ts)
  main.ts      сборка приложения: единственное место, где двигается окно
  app-info.ts  имя, версия и автор — одна точка правды для интерфейса
public/
  icon.svg     векторный логотип для favicon и карточки «О приложении»
scripts/
  make-icon.mjs  генератор PNG-набора и .ico (без зависимостей)
src-tauri/
  src/main.rs       точка входа и регистрация команд
  src/metrics.rs    снимок системы
  src/media.rs      SMTC: трек, обложка, управление, перемотка
  src/window_api.rs окно и системные действия
  capabilities/     разрешения Tauri
```

Слои идут строго в одну сторону: `ui → services → core/bridge → Rust`. Правила проекта (логирование, обработка ошибок, экранирование, доступность) описаны в [`system-design.md`](system-design.md).

## Приватность

- настройки и ключ ассистента хранятся только локально, в профиле WebView2 (`localStorage`);
- погода запрашивается у Open-Meteo — без ключа и аккаунта, кэш 10 минут;
- телеметрии, аналитики и фоновых отчётов нет: единственные сетевые запросы — погода и, если вы сами включили ассистента, запрос к указанному вами провайдеру.

## Чего нет — и почему

- **Запись экрана** — открывается системный Snipping Tool, где запись доступна; свой рекордер потребовал бы Media Foundation и отдельного окна.
- **Управление VPN** — Island показывает найденный VPN-интерфейс и открывает системные настройки; универсального API для сторонних клиентов нет.
- **Демонстрационных данных** — если нативной команды нет, раздел показывает «данные недоступны», а не выдуманные проценты.
- **Полоса капель — часть окна.** Клики по декоративной полосе под пилюлей (248 × 36) достаются островку, как и по его тени. Полностью убрать это можно только вторым окном или Win32 hit-test — ради декоративного эффекта такое усложнение не окупается; при желании эффект отключается в настройках.
