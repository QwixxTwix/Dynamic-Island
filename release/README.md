# Island 0.1.0

Первый публичный релиз. Портативная сборка для Windows 10/11: **один файл**, без установщика, без записи в реестр и без фоновых служб.

**Ассет релиза:** `island.exe` · 6 630 400 байт (6,63 МБ) · x64

**SHA-256:** `da859e963a0df97636a03758440527924b6bb6cf42fa6b1688bdd8f23c7b93e4`

Проверить скачанный файл: `Get-FileHash .\island.exe -Algorithm SHA256` в PowerShell (или `certutil -hashfile island.exe SHA256`).

## Что внутри

**Пилюля у верхнего края экрана**

- мини-персонаж — пара глаз: моргает, следит за курсором, оглядывается без движения мыши; настроение зависит от музыки, таймера, ночи, нагрузки CPU и заряда батареи;
- капли, стекающие снаружи островка: распределены по всей нижней кромке, набухают, срываются и падают; тонируются акцентом темы;
- живые активности меняются каждые ~5 секунд: трек, таймер, погода, CPU и память;
- часы, счётчик непрочитанных уведомлений, индикатор состояния;
- оба эффекта отключаются в настройках.

**Панель из пяти разделов**

- **Обзор** — часы, погода с прогнозом на 4 дня, плеер «Now Playing» с настоящей перемоткой, быстрые действия Windows, лента уведомлений;
- **Система** — CPU, память, диск, батарея, сеть, топ процессов, аптайм, сведения о машине, найденный VPN;
- **Фокус** — таймер с кольцом прогресса и уведомлением по завершении;
- **Ассистент** — локальные команды без интернета и свободные вопросы через любой OpenAI-совместимый API;
- **Настройки** — поверх окон, секунды, сквозные клики на 60 секунд, эффекты, поиск по любому городу мира, `°C`/`°F`, 10 акцентов, интервал опроса, журнал диагностики.

## Установка

1. Скачайте `island.exe` из этого релиза.
2. Положите в любую папку и запустите.
3. Пилюля появится по центру верхнего края основного монитора.

Нужен **WebView2 Runtime**: в Windows 11 он встроен, в Windows 10 обычно уже стоит вместе с Edge.

> Сборка не подписана сертификатом разработчика, поэтому SmartScreen может показать предупреждение — «Подробнее» → «Выполнить в любом случае». Исходный код открыт, файл собран из него командой `npm run exe`.

## Управление

| Действие | Как |
| --- | --- |
| Раскрыть / свернуть панель | клик по пилюле |
| Свернуть | `Esc` |
| Перемотка трека | тянуть скраббер или `←` / `→` / `Home` / `End` |
| Пропустить мышь сквозь окно | «Сквозные клики» в настройках (60 секунд) |
| Выйти | Настройки → «Выйти из Island» |

## Известные ограничения

- только Windows 10/11 x64;
- перемотка и метаданные зависят от плеера: нужен источник SMTC (Spotify, AIMP, браузеры, «Медиаплеер»);
- декоративная полоса капель под пилюлей — часть окна, поэтому клики по ней достаются островку;
- запись экрана и управление VPN открывают системные средства: универсального API для них нет.
